# 画面仕様・ワイヤー

各スケッチは情報の順と優先度を示す低精細ワイヤーであり、色・余白・文字の共通規則は[README](README.md)を適用する。ID・パスは詳細設計書§3に一致させる。全23画面を本書内で個別に扱う。

## 共通ワイヤー型

### 公開・会員ページ

│パンくず／ページ見出し  │         │パンくず／見出し    │

├───────────────────────┤         ├───────────────────┤
│フッター                │         │フッター             │

スマートフォン 0–767px

### 管理ページ

```text

Phone: [管理ヘッダー／ナビ開閉] [見出し／絞り込み] [行カード／行操作]
```

## 公開探索・商品

### S01 — トップ `/`

- **ワイヤー**: 共通公開ヘッダー → 用途別案内（ゲーム・普段使い・動画編集） → 8カテゴリ → 初心者向け選び方 → 公開商品の案内 → 共通フッター。
- **操作・遷移**: 検索語を入力して検索（S03）、カテゴリ選択（S02）、用途選択は結果条件へ、構成確認（S05）、カート・会員操作。
- **幅**: PCは用途カード3枚とカテゴリ/商品3–4列。Tabletは2列、補助ナビ折りたたみ。Phoneは用途カードと商品を1列、カテゴリ横スクロール、検索をヘッダー直下。
- **状態・復帰**: 用途に掲載商品がない場合も用途説明を残しS02へ。読込中は用途・商品カード形状のスケルトン。取得失敗は再試行とカテゴリ探索を示す。空のトップを真っ白にしない。
- **キーボード**: ページ見出しから用途・カテゴリ・検索へ順に移動。用途カードはリンクとして全体を操作できる。

### S02 — カテゴリ `/categories/[slug]`

- **ワイヤー**: 共通ヘッダー → パンくず・カテゴリ説明 → 仕様/価格/在庫/メーカー絞り込み + 並べ替え → 件数 → 商品カード → ページ送り。
- **操作・遷移**: カテゴリ固有項目は要件定義書の一覧どおり。条件変更、解除、ページ送り、商品選択でS04。
- **幅**: PCは左260pxの絞り込みと右3–4列の商品。Tablet/Phoneは絞り込み開閉パネル、Tabletは2列、Phoneは1列。
- **状態・復帰**: 不正slugは404相当とS01/S02一覧への導線。0件はカテゴリと条件を保って「条件解除」。読み込みは絞り込みとカード骨格を表示。失敗時は再試行、条件は保持。
- **キーボード**: 絞り込み開閉は状態を読み上げ、変更後の件数を通知。ページ送り後は一覧見出しへフォーカスを移す。

### S03 — 検索 `/search`

- **ワイヤー**: 共通ヘッダー → 検索語・用途・カテゴリ → 共通/カテゴリ別フィルター → 適用条件チップ・結果件数 → 商品カード → ページ送り。
- **操作・遷移**: キーワード、価格帯、メーカー、カテゴリ仕様を入力。URLクエリに検索条件を保持・共有し、商品選択はS04。
- **幅**: PCは左フィルター260px + 3–4列結果。Tablet/Phoneは開閉フィルター、2列/1列結果。
- **状態・復帰**: 未入力は全公開商品。0件でも条件を残して個別/一括解除とS01を示す。入力長超過は説明を該当欄へ、値を消さない。読込失敗は条件を保持して再試行。
- **キーボード**: 検索欄から結果件数・一覧へ移動可能。絞り込み変更後もフォーカスを奪わない。

### S04 — 商品詳細 `/products/[slug]`

- **ワイヤー**: パンくず → 画像ギャラリー + 商品名/SKU/税込価格/販売可能数/仕様/初心者向け説明 → 数量 → 「カート追加」「構成に追加」。
- **操作・遷移**: 数量1–10。カート追加後S06へ戻れる。構成へ追加はS05。画像は代替テキスト付き。
- **幅**: PCは画像・仕様・購入欄の2–3領域。Tabletは画像と情報の2列。Phoneは画像、価格/在庫、仕様、操作を縦積み。購入操作は合計・在庫の近くに置く。
- **状態・復帰**: 非公開/存在しないslugは404相当。販売可能0は「在庫切れ」とし追加を無効化。追加中に在庫不足なら最新数と数量再指定を行内表示。読込は画像と仕様の骨格、失敗は再試行とカテゴリへ。
- **キーボード**: ギャラリーの前後移動、数量ラベル、在庫説明、操作順を明示。

## 構成・カート・購入

### S05 — 構成確認 `/build`

- **ワイヤー**: 見出し/一時保存の説明 → CPU/GPU/マザーボード/メモリ/SSD/電源/ケース/クーラー選択カード → 互換性判定5項目 → 適合商品リンク → 商品別カート操作。
- **操作・遷移**: 商品を検索・選択・解除し、比較値と理由を見る。一時選択はURLまたはブラウザ内だけ。適合商品の探索はS02/S03、選択商品の詳細はS04、購入はS06。
- **幅**: PCはカテゴリカード2列、判定結果を比較値と横並び。Tabletもカード2列で判定結果は下段。Phoneはカテゴリと判定を1列、長い比較値を折り返す。
- **状態・復帰**: 未選択は必要部品を促す。読み込み中はカテゴリ単位のスケルトン。通信失敗は選択を保持して再試行。5項目は「一致/不一致/判定不能」を理由・比較値と表示し、不足値を示す。不一致でもカート/購入導線を残し、モーダルを出さない。
- **キーボード**: カテゴリ、商品選択、判定詳細を見出し順に操作。判定更新後、フォーカスを保持して結果の更新を通知。

### S06 — カート `/cart`

- **ワイヤー**: 明細行（画像/商品/単価/数量/行小計/削除） → 商品小計 → 「送料概算」 → 税込合計見込み → 会員購入操作。
- **操作・遷移**: 数量変更1–10、行削除、商品詳細へ戻る。未ログインの購入はS07を経由、会員はS12へ。
- **幅**: PCは明細と合計欄を2列。Tabletは明細を広くし合計を下段可。Phoneは各明細カード1列、数量/削除を行内に置き、合計と次操作を明細後に配置。
- **状態・復帰**: 空ならS01/S02/S03へ。価格変更・在庫不足・販売終了は該当行に最新値と再確認操作。更新失敗は入力数量を保持して再試行。読込は明細骨格。送料は必ず「概算」と明示。
- **キーボード**: 各数量・削除に商品名を含むラベル。行削除後は次の行か空状態見出しへフォーカス。

## 認証

### S07 — ログイン `/login`

- **ワイヤー**: 共通ヘッダー → ログインフォーム（メール、パスワード、表示切替） → ログイン → Google → 再設定/登録へのリンク。
- **操作・遷移**: 通常ログインとGoogleログインはSMS照合を要求しない。安全な同一サイト内の戻り先だけを保持し、成功は戻り先またはS15。購入復帰はS12へ。Google後も同じ戻り先規則。
- **幅**: すべてフォーム中心の単列。PCは適度な幅のカード、Tablet/Phoneは左右余白を確保しPhoneでは全幅に近づける。
- **状態・復帰**: 読込中は送信中表示と二重送信抑止。資格情報不正でもアカウント有無を示さない共通文言。通信失敗は入力を保持し再試行。再設定はS10、登録はS08。
- **キーボード**: メール→パスワード→表示切替→送信の順。エラー要約から欄へ戻る。

### S08 — 新規登録 `/register`

- **ワイヤー**: メール、パスワード、確認、規約/個人情報案内、登録操作。
- **操作・遷移**: 入力を検証し登録、成功はS09。パスワードと確認値は要件の検証目的以外に表示・保存しない。
- **幅**: PCは読みやすい単列フォーム。Tablet/Phoneは同じ単列、767px以下でフィールドを横並びにしない。
- **状態・復帰**: 読込中は登録操作を抑止。形式/強度/不一致は欄下に説明し、他の入力を維持。送信失敗は再試行。登録成功はメール確認待ちをS09で案内。
- **キーボード**: 各欄ラベル、要件説明、関連エラーを順に読み上げる。

### S09 — メール/SMS確認 `/verify`

- **ワイヤー**: メール確認状況と再送 → 公開デモの模擬SMS説明（実送信/電話番号収集なし） → 6桁コード入力 → 確認/再発行。
- **操作・遷移**: コード発行・入力・照合・再発行。両確認後にS15または購入時の安全な戻り先。模擬コードが電話番号所有を証明しないことを明示。
- **幅**: 3幅とも単列。Phoneは6桁入力欄を画面内に収め、入力中の横スクロールを避ける。
- **状態・復帰**: 読込は確認段階ごとの状態。期限切れ/試行超過は再発行可能時点と次操作を示す。無効コードは再入力を許可。メール再送失敗は状態を未確認のまま保ち再試行。
- **キーボード**: コードは一つの論理入力として扱い、貼り付け・編集・誤入力修正ができる。

### S10 — パスワード再設定 `/reset-password`

- **ワイヤー**: メール送信段階 → メールリンク経由の新パスワード/確認 → 6桁模擬SMS照合 → 完了案内。
- **操作・遷移**: フローごとの段階を明示し完了後S07。コード再送・リンク再送の残り時間と次操作を案内。
- **幅**: 全幅で段階を縦に積む単列。Phoneは長い案内を折り返し、主操作は入力欄直後。
- **状態・復帰**: 期限切れリンク/コードは同じ画面で再申請。再送制限は解除時点を表示。入力不備は値を失わず欄に関連付け。通信失敗は再試行。
- **キーボード**: 段階変更を見出しで通知し、送信後はエラー要約または次段階へフォーカス。

## 会員・注文履歴

### S11 — 配送先管理 `/account/addresses`

- **ワイヤー**: 会員ナビ → 配送先一覧/既定表示 → 新規/編集フォーム（氏名、郵便番号、都道府県、市区町村、番地、建物、既定） → 保存/削除。
- **操作・遷移**: 架空情報の使用を案内。削除確認で対象を具体的に示す。終了後は元画面またはS15/S12へ。
- **幅**: PCは一覧とフォームを2列可、Tabletはフォームを下段可。Phoneは住所カード一覧とフォームを単列。
- **状態・復帰**: 空なら新規登録を案内。読込中は住所カード骨格。形式エラーは欄下、値を保持。保存/削除失敗は対象を残して再試行。権限エラーはS07または拒否表示。
- **キーボード**: 行操作に住所の識別名、削除確認に対象住所の要約を使う。

### S12 — 購入用配送先 `/checkout/address`

- **ワイヤー**: 購入ステップ表示 → 保存先選択または新規入力 → 注文用住所の確認 → 続行。
- **操作・遷移**: 会員限定。保存先選択または追加後S13。住所管理はS11。戻る操作でS06。
- **幅**: PCは住所選択と要約を2列。Tabletは2列または縦積み。Phoneは住所カードとフォームを単列。
- **状態・復帰**: 住所なしはその場で入力。国内形式エラーを欄下に表示。未認証はS07、ログイン後は安全な購入復帰先へ。カート空/売切れは理由を示してS06。見積/住所取得失敗は値を保持して再試行。
- **キーボード**: 住所選択はラジオ等の明確な選択状態を使い、現在の選択を音声でも識別する。

### S13 — 注文確認 `/checkout/review`

- **ワイヤー**: 購入ステップ → 商品行/注文用住所 → 互換性警告 → 正式送料内訳/税/合計 → 模擬決済の注記 → 金額確認後の決済操作。
- **操作・遷移**: 配送先変更はS12、カート変更はS06。サーバーの正式見積を確認して決済先へ進む。クライアントで金額を確定しない。
- **幅**: PCは明細左・金額サマリー右。Tabletは金額サマリーを本文の後方に置ける。Phoneは明細→住所→警告→内訳→合計→決済操作の順。
- **状態・復帰**: 価格/送料再計算差異は更新額を表示し、確認し直してから続行。互換性不一致は短い非モーダル警告を表示し購入を妨げない。在庫不足は商品とS06への導線。送料算定不能は理由と停止状態を明示。読込中はサマリー骨格、通信失敗は再取得。
- **キーボード**: 合計・警告を決済操作の直前に読める順にする。操作時に確認した確定額が同じ画面で追える。

### S14 — 決済結果 `/checkout/result`

- **ワイヤー**: 注文識別情報 → サーバー取得の状態（処理中/成功/失敗/期限切れ） → 状態ごとの次操作。
- **操作・遷移**: 成功確定後S17。履歴S16。失敗時は再試行またはS06。戻りURLだけでは成功にしない。
- **幅**: 全幅で状態見出し→説明→主操作の単列。結果要約は幅に合わせて折り返す。
- **状態・復帰**: Webhook未着は「確認中」と再読込操作。読込失敗も未確定を成功に見せず再試行。失敗は原因と次の操作。期限切れは再試行導線。状態ラベルとアイコンを併用。
- **キーボード**: 状態変化を見出しとして読み上げ、再読込操作を利用者が選択できる。

### S15 — マイページ `/account`

- **ワイヤー**: 会員概要 → 配送先/注文履歴リンク → ログアウト/アカウント削除 → 架空情報・30日削除の説明。
- **操作・遷移**: 配送先S11、履歴S16、ログアウトS01。削除は再認証・確認後に実行しS01へ。
- **幅**: PCは概要カードを2–3列、Tablet2列、Phone1列。重要操作は説明から離しすぎない。
- **状態・復帰**: 未ログインS07。注文なしは探索S01/S02。読込失敗は再試行。削除失敗は理由を表示し再試行またはサポート導線。
- **キーボード**: 削除操作は破壊的操作と明示し、確認後キャンセル時は元のボタンへ戻る。

### S16 — 注文履歴 `/account/orders`

- **ワイヤー**: 会員ナビ → 日付/税込金額/状態の注文一覧 → 注文ごとの詳細操作。
- **操作・遷移**: 自分の注文だけ表示。注文行からS17。
- **幅**: PCは一覧表、Tabletは重要列と詳細リンク、Phoneは1注文1カードに変換。
- **状態・復帰**: 空なら商品探索。読込は行/カード骨格。取得失敗は再試行。認証切れS07。注文対象なしの個別取得はS17側で404相当。
- **キーボード**: 各リンク名に注文日/状態など識別情報を含め、表見出しを関連付ける。

### S17 — 注文詳細 `/account/orders/[id]`

- **ワイヤー**: 注文状態と決済状態 → 注文時の商品/単価/数量/住所スナップショット/送料/税/合計 → 次操作。
- **操作・遷移**: 履歴S16、決済結果の確認、失敗時は再試行可能な導線。
- **幅**: PCは明細と合計を2列、Tabletは2列または縦積み、Phoneは商品行と全金額を単列。
- **状態・復帰**: 読込は注文要約骨格。未確定は確認中。決済失敗は再試行。別会員の注文は存在を示さない404相当。通信失敗は未確定表示と再試行。
- **キーボード**: 合計・状態を見出し構造で読み上げ、長い住所は適切に折り返す。

## 管理

管理画面は管理者のみ利用でき、ECのヘッダーと分ける。一般会員のURL直打ちは認可エラーとして扱い、非表示化だけで制御しない。

### A01 — 管理ダッシュボード `/admin`

- **ワイヤー**: 管理ヘッダー/サイドナビ → 公開商品・在庫不足・注文・通知障害の件数カード → 各管理画面へのリンク。
- **操作・遷移**: 商品A02、在庫A03、注文A04、送料A05、メールA06。
- **幅**: PCカード3–4列+固定サイドナビ、Tablet2列+折りたたみナビ、Phone1列+開閉ナビ。
- **状態・復帰**: 非管理者403。件数0は「対象なし」。読込骨格、取得失敗は再試行。障害件数は対象一覧へ移動。
- **キーボード**: サイドナビに現在地を示し、数値だけでなくカード名も読み上げる。

### A02 — 商品管理 `/admin/products`

- **ワイヤー**: 見出し/新規 → 検索・公開状態 → 商品一覧 → 8カテゴリ仕様/価格/重量・寸法/画像の編集フォーム。
- **操作・遷移**: 商品検索、新規、編集、公開状態変更。編集画面の項目は選択カテゴリに対応する。
- **幅**: PCは表+フォーム領域、Tabletは重要列と詳細画面、Phoneは1商品1カードで行全体から編集。
- **状態・復帰**: 空なら新規作成。読込は表/フォーム骨格。必須仕様不足は下書き保存可、公開時は欄単位に拒否理由。保存失敗は入力を保持。
- **キーボード**: 表の操作を行単位で識別し、フォームのエラー要約から該当欄へ移動。

### A03 — 在庫管理 `/admin/inventory`

- **ワイヤー**: 商品検索/フィルター → 商品別実在庫・引当中・販売可能数 → 調整理由/数量入力 → 更新履歴表示。
- **操作・遷移**: 商品を選び調整理由と数量を送信。原子的結果は最新値とともに表示。
- **幅**: PCは表、Tabletは重要列+詳細、Phoneは在庫指標を含む商品カード。調整欄は画面内の明確な主操作。
- **状態・復帰**: 空は対象商品なし。読み込み骨格。負数や引当数を下回る調整は拒否し値を保持。競合は最新値と再確認を表示。通信失敗は重複適用と誤認させず結果再確認を案内。
- **キーボード**: 商品・現在値・調整欄の順に移動。危険な負在庫条件を欄の説明に関連付ける。

### A04 — 注文管理 `/admin/orders`

- **ワイヤー**: 検索/状態フィルター → 注文/決済試行/監査の参照一覧 → 注文詳細。
- **操作・遷移**: 注文を絞って詳細を読む。決済状態は編集しない。
- **幅**: PCは表、Tabletは重要列、Phoneは注文単位のカード。
- **状態・復帰**: 空は「対象なし」。読込骨格。失敗はフィルターを保持して再試行。アクセス拒否は403。状態操作がないことを視覚上も区別。
- **キーボード**: 参照リンクを注文識別情報付きにし、表の列見出しと値を対応させる。

### A05 — 送料設定 `/admin/settings/shipping`

- **ワイヤー**: 発送元 → 通常送料940円/税込商品小計1万円の閾値 → 20kg以上の商品別公式運賃表 → 出典URL/確認日/規則版 → 差分確認/保存/監査。
- **操作・遷移**: 設定を編集し、保存前に差分と監査対象を確認。料金の適用詳細は設計の設定項目に従う。
- **幅**: PCは項目と出典を2列、Tablet/Phoneは縦積み。料金行はPhoneで行カード化し出典URLを折り返す。
- **状態・復帰**: 読込骨格。欠損/対象運賃なしは正式見積不可の理由を表示。検証失敗は欄下。保存失敗は入力を保持。保存前に変更差分を表示。
- **キーボード**: 料金表行に地域・サイズ等の識別見出し、URLに意味のあるリンク名。

### A06 — メール設定 `/admin/settings/email`

- **ワイヤー**: SMTPホスト/ポート/送信元/TLS → 秘密入力欄（値は表示しない） → 保存 → 接続試験 → 結果。
- **操作・遷移**: 設定保存と接続試験を別操作にする。秘密は再表示しない。
- **幅**: PCは接続項目と補助説明の2列、Tablet/Phoneは単列。秘密欄が狭幅で切れないようにする。
- **状態・復帰**: 読込中も秘密の値やマスク長を示さない。秘密未登録/登録済みを値なしの状態ラベルで示す。試験失敗は原因を秘密抜きで表示し、再試行/設定修正へ戻す。保存失敗は非秘密入力を保持。
- **キーボード**: 秘密欄の説明、保存、試験、結果の順。接続試験結果はフォーカス可能な見出しで読み上げる。
