# 自作PCパーツECサイト 企画書

**ステータス：企画フェーズ完了**  
**対象：ポートフォリオ用Webシステム**  
**更新日：2026年9月24日**

## 1. 企画の目的

初めて自作PCを組む人が、用途からパーツを探し、基本的な互換性を確認しながら、安心して購入手続きを進められるECサイトを制作する。経験者には、メーカー・規格・価格・性能などを用いた効率的な商品探索も提供する。

本プロジェクトでは完成したサイトに加え、企画、要件定義、基本設計、UI設計、データベース・API設計、実装、レビュー、テスト、CI/CD、公開、運用を想定した改善までを一つの開発事例として提示する。

実際の販売、課金、発送は行わない。ただし、商品・仕様・在庫・会員・配送先・注文・決済状態はバックエンドで扱い、実際のECサイトを想定した購入体験と業務処理を再現する。

## 2. 対象利用者と提供価値

### 主な対象：初めて自作PCを組む人

- ゲーミング、普段使い、動画編集などの用途を入口に商品を探せる。
- パーツの役割、選ぶ際に確認すべき仕様、互換性の判定理由を理解できる。
- 選んだ商品をカートに入れ、注文完了までの流れを体験できる。

### 対象：自作PCの経験者

- カテゴリ、メーカー、規格、価格、性能などから商品を検索・絞り込みできる。
- 商品仕様と在庫状況を確認し、効率よく購入手続きを進められる。

### 管理者

- 管理画面から商品、税込価格、在庫、互換性判定に必要な仕様を登録・編集できる。
- 注文と決済の状態を確認できる。

## 3. 初期版のサービス範囲

| 領域 | 企画上の範囲 |
| --- | --- |
| 商品 | CPU、GPU、マザーボード、メモリ、SSD、電源、PCケース、CPUクーラーを扱う。ポートフォリオ用データを使用し、実在製品の仕様を参考にしてよい。 |
| 探索 | カテゴリ、キーワード、用途別の導線、およびメーカー・規格・価格・性能などによる検索・絞り込みを提供する。 |
| 商品検討 | 商品詳細に仕様、税込価格、在庫状況、初心者向けの説明を示す。 |
| 構成確認 | 選択したパーツについて、初期版で定めた基本的な互換性を確認できる。 |
| 会員 | 会員登録、ログイン、配送先管理、注文履歴を提供する。注文には会員登録を必須とする。 |
| 購入 | カート、注文確認、テスト環境での決済、注文完了までを提供する。 |
| 国内向け注文 | 日本国内の配送先を扱う。表示価格は税込とし、注文金額には商品金額、消費税、送料を反映する。注文データに配送先、商品金額、消費税、送料を保持する。 |
| 管理 | 商品・価格・在庫・仕様の登録と編集、注文・決済状態の確認を提供する。 |
| 業務処理 | 商品、在庫、注文、決済、ユーザーの情報をバックエンドで処理する。 |

商品数は企画段階で固定しない。互換する組み合わせ、互換しない組み合わせ、判定に必要な仕様が不足した組み合わせを含め、検索・絞り込み・在庫管理も検証できるデータ構成を要件定義時に決める。

## 4. 互換性チェックの範囲

初期版では次の組み合わせを対象にする。

1. CPUとマザーボードのSocket
2. マザーボードとメモリのDDR規格
3. マザーボードとPCケースのフォームファクター
4. GPUとPCケースの搭載可能サイズ
5. CPUクーラーとCPU Socket

判定結果は、互換する、互換しない、情報不足などで判定できない状態を区別し、比較した仕様と理由を利用者に示す。初期版の判定範囲外の条件まで含めて「構成全体の動作を保証する」表示はしない。

高度な互換性判定と、選択したPC構成の保存・再編集は将来拡張とする。構成保存を後から追加できることを設計時に考慮する。

## 5. 正常系と異常系の体験

通常の購入に加え、利用者が次の状態を確認できるデモ用の商品またはテスト方法を用意する。

- 在庫切れ
- 注文処理中の在庫不足
- 決済成功
- 決済失敗
- 互換性不一致
- 互換性判定に必要な情報不足

異常系では、原因と次に取れる操作が分かる表示を提供する。具体的な状態遷移、在庫処理、テスト方法は要件定義と設計で定める。

## 6. 初期版に含めないもの

- 実際の商品販売、実課金、発送
- ゲスト注文
- 外部ECサイトからの商品情報取得、価格連携
- 高度な互換性判定、および構成の保存・再編集
