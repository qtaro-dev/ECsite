# 自作PCパーツECサイト

**パーツを選ぶ楽しさを、もっとわかりやすく。**

自作PCが初めての方も、パーツに詳しい方も、用途や性能から商品を探せるECサイトのポートフォリオ作品です。商品探しからカート、注文までの流れを体験できるよう、画面とバックエンドの両方を開発しています。

**[公開デモを開く](https://ecsite-jade.vercel.app/)**

> このサイトは制作・検証用のデモです。**実際の商品販売・請求・発送は行いません。** 決済にはStripeのテストモードを使用します。

## できること

- **商品を探す**：キーワード検索やカテゴリから、CPU・グラフィックボード・メモリなどのPCパーツを探せます。
- **用途から完成PCを選ぶ**：ゲーム、日常利用、動画編集などの目的に合わせて、構成済みPCを比較できます。
- **パーツの相性を確認する**：PC構成を検討するときに、互換性に関する情報や注意点を確認できます。
- **カート・購入体験**：商品をカートに入れ、配送先、送料を含む見積もり、注文、テスト決済までの流れを用意しています。
- **デモ会員で試す**：メールアドレスなどを登録せず、閲覧者ごとのデモ会員として購入操作を体験できます。
- **管理機能**：商品・在庫・完成PC・送料設定などを扱う管理者向け画面も実装しています（一般の閲覧者には公開していません）。

## デモ利用時のご案内

- 実在する個人情報や本物のカード情報は入力しないでください。
- デモ会員のデータは閲覧者ごとに分離されます。デモ会員のセッションを失うと、同じ会員として再開できない場合があります。
- 決済はテスト用です。通常の買い物としての商品購入はできません。
- 一般向けの会員登録・通知メールなど、公開後に対応する機能もあります。
- 一部の決済異常系・運用処理には、開発記録上まだ追加検証が必要な項目があります。**すべての機能・動作を検証済みという意味ではありません。**

## 使用技術

Next.js / React / TypeScript / Supabase（データベース・認証・ストレージ） / Stripe（テスト決済） / Vercel

品質確認にはVitest、Playwright、GitHub Actionsなどを使用しています。

## ローカルで動かす場合

開発環境は **Node.js 24.x** とnpmを使用します。

```powershell
npm ci
npm run dev
```

ブラウザーで `http://localhost:3000` を開きます。

**商品データ・会員認証・カート・注文などの機能には、Supabase等の環境設定が必要です。** 上記コマンドだけですべての機能が動くわけではありません。設定項目と手順は[環境構築手順](docs/environment-setup.md)を確認してください。実際の接続情報や秘密鍵はGitHubに登録しないでください。

コードの確認には以下を使用できます。

```powershell
npm run typecheck
npm run lint
npm test
npm run build
```
