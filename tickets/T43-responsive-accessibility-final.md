**状態**：未着手  
**フェーズ**：M7 品質・CI/CD・公開

## 目的

全画面を公開ECとして使いやすくする。

## 対応要件ID

| ID | 要件定義書の要件 |
| --- | --- |
| CAT-01 | カテゴリ、キーワード、用途から商品を探せる。 |
| CAT-02 | メーカー、規格、価格、性能などで絞り込める。カテゴリごとの項目は後述の一覧を基準とする。 |
| CAT-03 | 商品詳細に仕様、税込価格、販売可能な在庫状況、初心者向けの説明を表示する。 |
| CMP-04 | 不一致の理由と、適合する商品を探すための具体的な導線を表示する。 |
| ORD-01 | 会員がカート、注文確認、テスト決済、注文完了、注文履歴を利用できる。 |
| QLT-01 | 主要操作、異常系、権限、在庫・金額の整合性について受け入れ条件を作る。 |

要件定義書の「詳細化待ち」および古い確認待ち表記は、後続の利用者承認と詳細設計の確定内容を適用する。

## 対象範囲

- S01–S17/A01–A06の全画面レイアウト。

## 実装内容

- S01–S17/A01–A06の0–767/768–1199/1200px以上、320px、200%拡大、44px操作領域、フォーカス、読み上げ、コントラスト、管理表カード化を調整。
- 0–767/768–1199/1200px、320px、200%拡大、44px、色以外の状態、キーボード、管理表カード化を全画面で調整する。
- 入出力・DB・権限・画面に変更がある場合は、同じチケット内で対応するOpenAPI、Zod、マイグレーション、RLS、テスト、文書を整合させる。

## 対象外

- 設計配色の独自変更、チケット外の業務仕様変更。
- 他チケットの機能と、正本にない仕様の独断追加。必要なら変更案を報告する。

## 受け入れ条件

- 主要操作に横スクロール・隠れたボタンがなく、警告は色以外でも理解できる。
- 主要操作が隠れず、WCAG 2.2 AAの対象基準を満たす。
- 設計との不整合、秘密・個人情報の露出、権限の迂回がない。外部設定が未完了なら接続確認を完了扱いにしない。

## 必要なテスト

- Playwright PC/タブレット/スマホ、axe等の自動検査とキーボード手動確認。
- Playwright各幅、axe等と手動キーボード/読み上げ確認を行う。
- 該当する境界・異常・権限のケースを実行し、既存の関連回帰テストも通す。実行できない場合は理由を記録する。

## 完了条件

- 対象範囲の成果物と受け入れ条件が揃い、指定テストの結果を記録した。
- チケット外の変更、設計上の疑問、外部作業の未完了を隠さず報告した。
- 変更点、設計根拠、テスト結果、残課題をLUNAの完了報告に記載し、レビュー可能な差分になっている。
