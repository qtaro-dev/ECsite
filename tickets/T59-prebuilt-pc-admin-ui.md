# T59 構成済みPCの管理画面

**状態**：未着手  
**担当**：LUNA-B  
**要件ID**：CAT-04、CAT-05、SEC-01、QLT-01  
**依存**：T58完了・マージ、T57・T56・T37・T38・T53のマージ済み成果。

## 目的

管理画面から構成済みPCを登録・編集できる専用フォームを追加する。管理者はCPU/GPU/メモリ/SSD等の採用パーツ名と説明を自由入力し、用途、価格、商品情報を保存できる。構成部品の商品SKU検索や在庫連動は行わず、在庫は完成PCの独立SKUとして既存管理画面で扱う。

## 参照・設計根拠

- T58が定義する専用管理API/Zod契約とエラー応答を使用し、ブラウザーからDBを直接更新しない。
- T53の構成JSONB（CPU、GPU、メモリ、SSD必須、任意でマザーボード/電源/ケース）および`gaming`、`daily`、`editing`用途を表示・編集する。
- T37の既存商品編集（商品名、税込価格、公開状態、画像、重量・梱包寸法等）とT38の在庫編集を混同しない。T57で追加済みのslug入力ヘルプとアクセシビリティ属性を維持する。

## 対象範囲

- 管理商品一覧から構成済みPCの作成・編集へ遷移し、既存の「シード管理／SQL管理」表示を専用管理導線へ置き換える。
- 商品情報、税込価格、用途選択、各構成部品の名前・詳細、画像、公開状態、重量/梱包寸法を編集する専用フォーム。
- 下書きの空状態、フィールド単位の検証エラー、保存中、競合/失敗、成功状態を実装する。
- API経由の保存と既存商品一覧への反映。

## 対象外

- 単品パーツ商品との連携、選択UI、BOM、構成部品在庫の表示や変更。
- 在庫数の編集（既存T38画面を利用）。本フォームの保存で完成PCまたは構成部品在庫を変化させない。
- 公開側の完成PC表示・購入フローの変更。

## 受け入れ条件

- 管理者が新規下書きを作成し、採用パーツ名・仕様を自由入力して保存後、再編集画面で値を確認できる。既存完成PCの編集でも値が欠落・破損しない。
- CPU/GPU/メモリ/SSD、任意構成、用途、価格、画像、重量・梱包寸法、公開状態をT58契約どおり扱う。構成未入力の下書きを保存でき、公開条件の不足は該当欄に説明する。
- 保存成功時にT58 APIを使用する。管理者以外は管理画面へ入れず、認可エラーを適切に表示する。
- 編集操作で完成PC SKUの在庫も単品パーツ在庫も変化しない。T38在庫画面から完成PC在庫を独立して管理できる。
- T57のslugヘルプ、既存8カテゴリの編集導線、画像操作が維持される。
- 320px幅、200%拡大、キーボードのみで操作でき、表示幅別（スマートフォン/タブレット/PC）で崩れず、主要操作のターゲットサイズ44px以上を確保する。

## 必要なテスト

- Playwrightで新規下書き作成、構成入力・保存・再編集、既存PC編集、公開時不足エラー、画像操作、API失敗/競合を確認する。
- 管理者/非管理者の画面・API境界と既存8カテゴリのT37回帰を確認する。
- 在庫がフォーム保存で変化せず、T38経由では完成PC独立SKUのみ調整できることを検証する。
- 320px、代表タブレット/PC幅、200%拡大、キーボード操作、44px操作領域を確認する。

画面/API接続、Playwright結果、アクセシビリティ確認、T37/T38/T53回帰を記録する。未実行テストや表示上の制約を合格扱いにしない。
