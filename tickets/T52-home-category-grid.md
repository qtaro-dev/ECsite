# T52 ホームカテゴリカードの均等幅レイアウト

**状態**：未着手

**担当**：LUNA-B
**一覧へ戻る**：[implementation-tickets.md](../docs/implementation-tickets.md)

## 目的

ホームの「パーツから探す」8カテゴリカードを、PC幅でセクション全体を使った均等幅の4列×2段にする。現在は画面幅が広くてもコンテンツ最大幅に合わせて左右に余白が大きく残るため、カテゴリセクションを横幅いっぱいに広げ、カードを見つけやすくする。

## 対応範囲

- ホームカテゴリセクションの横幅・左右余白と、8カードのPC配置。
- デスクトップでの4列×2段、列幅の均等性、画面端までの横はみ出し防止をPlaywrightで検証する。
- 現行のタブレット3列・スマートフォン2列のレスポンシブを維持する。

## 対象外

- 「何をしたいかから探す」の用途別導線とBTO構成への誘導。これは後続T54で扱う。
- 商品データ、検索・カテゴリ遷移、画像・Resource素材、ヘッダー、フッター。

## 実施内容

1. ホームカテゴリセクションをPCで画面幅まで拡張し、過度な左右余白を抑えた一定の内側余白を設ける。
2. 1200px以上では8枚を均等幅の4列×2段で表示する。
3. 768–1199pxの3列、767px以下の2列を保つ。320pxを含む各幅で横スクロールを発生させない。
4. PlaywrightでPCのセクション幅・列幅の均等性・列数/段数と、タブレット/スマートフォンの列数、横はみ出しを確認する。

## 受け入れ条件

- PC（1200px以上）でカテゴリセクションがviewportの横幅を活用し、8カードが均等幅の4列×2段になる。
- タブレット（768–1199px）は3列、スマートフォン（320–767px）は2列で表示される。
- PC/タブレット/スマートフォン各幅でdocument-levelの横はみ出しがない。
- 8つのリンク先とラベルは維持される。
- BTO用途別導線、Resource/、他の画面は変更しない。

## 必要なテスト

- 新設するPlaywrightテストで320、768、1199、1200、1440、1920 CSS pxを確認する。
- PCではセクションの左右端、カード幅の差（最大1 CSS px）、カード位置から判定した4列×2段を検証する。タブレット・スマートフォンでは既定列数と横はみ出しを検証する。
- 関連するcatalog/design-systemブラウザテストを実行する。
