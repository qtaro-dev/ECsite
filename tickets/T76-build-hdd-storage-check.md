# T76 構成確認へのHDD追加とストレージ補足

## 範囲・依存

T24・T73・T74後。構成確認のSSD直後にHDDを追加し、独立した検索・商品選択と共有URLに対応する。商品詳細の「構成に追加」からも選べる。

- 従来の5項目と購入処理の判定を維持し、SSDまたはHDDを選んだときに別枠でストレージの接続規格・ポート数を表示する。
- 任意のSATAポート数、M.2スロット数・対応規格、HDDの消費電力を管理画面で扱う。未登録と0を区別する。M.2 SATAはケーブル接続SATAと分けて数える。
- 仕様不足を確認不能とし、HDD単体が電源定格を超える場合のみ電力不足と判断する。M.2のレーン共有やPC全体の電力は保証しない。

## 公開順と検証

先に加算マイグレーションを適用してからアプリを公開する。既存商品に新仕様を推定で補完しない。既存のアクセス権・RLSを維持し、匿名公開境界、管理保存、注文スナップショット、従来の互換性、HDD・SSDの選択とURLをテストする。
