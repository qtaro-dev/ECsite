# T27 送料・税計算器

**状態**：未着手  
**フェーズ**：M5 金額と購入  
**推奨実装順**：24/47（番号順ではなく[実装計画](../docs/implementation-plan.md)第3章の順序）  
**一覧へ戻る**：[implementation-tickets.md](../docs/implementation-tickets.md)

## 目的

注文金額をサーバーで一意に確定する。

## 対応要件ID

| ID | 要件定義書の要件 |
| --- | --- |
| ORD-03 | 通常送料は全国一律を基本とし、税込商品代金10,000円以上で無料にする。北海道・沖縄県も対象とする。 |
| ORD-04 | ヤマト運輸の取扱いに合わせ、離島であることだけを理由に追加送料を課さない。20kg以上の商品は重量物とし、通常送料が無料でも重量に応じた追加送料を加算する。 |
| ORD-05 | ヤマト運輸の公式料金情報を参照して送料を定め、根拠となる公式ページへのリンクを表示する。発送元は東京都を初期設定とし、管理設定から変更できるようにする。 |
| ORD-08 | 決済方式、注文・在庫の状態遷移、送料の内訳と税額の計算規則を定める。 |
| ORD-09 | 初期版の取扱商品と送料は標準税率10%で計算する。表示・保存する商品価格と送料は税込とし、注文時点の適用税率と税額を保持する。税額の端数は税率ごとに注文単位で処理する。 |

要件定義書の「詳細化待ち」および古い確認待ち表記は、後続の利用者承認と詳細設計の確定内容を適用する。

## 対象範囲

- サーバー側の送料・税の純粋計算器。

## 実装内容

- 税込円整数、通常送料940円、商品小計1万円以上の通常無料、20kg以上の商品ごとのヤマト公式運賃、離島加算なし、標準税率10%の内税一回切り捨て。料金表版・根拠URL・東京都初期発送元を扱う。
- 940円、商品税込1万円以上で通常0円、20kg以上1点1梱包のヤマト公式運賃、離島理由の加算なし、10%内税を注文単位で一回切り捨てる。
- 入出力・DB・権限・画面に変更がある場合は、同じチケット内で対応するOpenAPI、Zod、マイグレーション、RLS、テスト、文書を整合させる。

## 対象外

- ライブ運賃API、ヤマト上限超過商品の販売、税率追加。
- 他チケットの機能と、正本にない仕様の独断追加。必要なら変更案を報告する。

## 受け入れ条件

- 住所・梱包・料金表欠損、ヤマト上限超過は金額を仮定せず決済不可。カート用概算と注文用正式見積を区別する。
- 料金表・梱包欠損はSHIPPING_UNAVAILABLE。発送元・料金版を結果に含む。
- 設計との不整合、秘密・個人情報の露出、権限の迂回がない。外部設定が未完了なら接続確認を完了扱いにしない。

## 必要なテスト

- Vitestで9,999/10,000円、19,999/20,000g、北海道・沖縄・離島、複数重量物、税端数、設定版変更。
- 9,999/10,000円、19,999/20,000g、北海道/沖縄/離島、複数重量物、端数を試す。
- 該当する境界・異常・権限のケースを実行し、既存の関連回帰テストも通す。実行できない場合は理由を記録する。
