# T21 配送先と会員画面

**状態**：未着手  
**フェーズ**：M3 認証と会員  
**推奨実装順**：21/47（番号順ではなく[実装計画](../docs/implementation-plan.md)第3章の順序）  
**一覧へ戻る**：[implementation-tickets.md](../docs/implementation-tickets.md)

## 目的

注文前に本人の国内配送先を管理できるようにする。

## 対応要件ID

| ID | 要件定義書の要件 |
| --- | --- |
| ACC-03 | 配送先などECに必要な追加情報は本サイトで入力する。 |
| ACC-07 | 会員は配送先と注文履歴を管理できる。 |
| ORD-01 | 会員がカート、注文確認、テスト決済、注文完了、注文履歴を利用できる。 |
| SEC-01 | テスト用の認証省略機能と管理権限を公開環境の一般利用者に開放しない。 |

要件定義書の「詳細化待ち」および古い確認待ち表記は、後続の利用者承認と詳細設計の確定内容を適用する。

## 対象範囲

- S11/S15と本人住所API。

## 実装内容

- S11/S15、住所CRUD・既定住所、郵便番号・都道府県・文字数検証、架空データ案内、注文復帰。OpenAPI/Zodを同期。
- 国内郵便番号・都道府県・既定1件・CRUD、架空情報案内、注文への復帰を実装する。
- 入出力・DB・権限・画面に変更がある場合は、同じチケット内で対応するOpenAPI、Zod、マイグレーション、RLS、テスト、文書を整合させる。

## 対象外

- 注文スナップショット、30日アカウント削除。
- 他チケットの機能と、正本にない仕様の独断追加。必要なら変更案を報告する。

## 受け入れ条件

- 本人だけ読み書きでき、住所なし・入力エラー・削除確認が明確。Google会員も本サイト側で入力する。
- 本人だけ読書き可。住所なし・入力エラー・削除確認を表示する。
- 設計との不整合、秘密・個人情報の露出、権限の迂回がない。外部設定が未完了なら接続確認を完了扱いにしない。

## 必要なテスト

- Vitest住所検証、Playwright登録/編集/削除、会員A/BのRLS拒否。
- 会員A/B越権、住所境界、Google会員入力、削除を試す。
- 該当する境界・異常・権限のケースを実行し、既存の関連回帰テストも通す。実行できない場合は理由を記録する。

- チケット外の変更、設計上の疑問、外部作業の未完了を隠さず報告した。
- 変更点、設計根拠、テスト結果、残課題をLUNAの完了報告に記載し、レビュー可能な差分になっている。
